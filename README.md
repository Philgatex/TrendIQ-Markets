# TrendIQ Markets

TrendIQ Markets is a real-time multi-market analysis, prediction scoring, and risk planning dashboard built with Python and Streamlit.

## Markets Covered

- Nasdaq-100 / US100 proxy
- S&P 500 / US500 proxy
- Dow Jones / US30 proxy
- Russell 2000
- FTSE 100
- Nikkei 225
- Hang Seng
- DAX
- Gold
- Silver
- WTI Crude Oil
- Brent Crude Oil
- Bitcoin
- Ethereum
- Major forex pairs
- US 10Y yield

## Features

- Global market regime scoring
- Technical indicators: EMA, RSI, MACD, ATR, Bollinger Bands
- Candlestick charts with Plotly
- Bullish, bearish, and sideways probability scoring
- Support and resistance detection
- Trade scenario levels
- Risk management and position-size estimation

## Deployment

Deploy on Streamlit Community Cloud:

- Repository: `Philgatex/TrendIQ-Markets`
- Branch: `main`
- Main file path: `app.py`
